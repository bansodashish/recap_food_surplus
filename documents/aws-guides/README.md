# AWS Guides

This directory contains all AWS-related setup and configuration documentation for the FreshFlo platform.

## 📚 Available Guides

### Authentication & User Management
- **AWS_COGNITO_SETUP.md** - Complete AWS Cognito User Pool configuration
- **COGNITO_DEBUG_GUIDE.md** - Debug common authentication issues  
- **COGNITO_TROUBLESHOOTING.md** - Troubleshoot Cognito problems

### Cloud Infrastructure
- **AWS_AMPLIFY_DEPLOYMENT.md** - AWS Amplify setup and deployment
- **S3_SETUP.md** - Amazon S3 bucket configuration for file uploads
- **SECURE_S3_SETUP.md** - Production-ready S3 security configuration

## 🎯 Quick Start
1. Begin with `AWS_COGNITO_SETUP.md` for user authentication
2. Configure file storage with `S3_SETUP.md`
3. Deploy using `AWS_AMPLIFY_DEPLOYMENT.md`

## 🔧 Troubleshooting
If you encounter issues, check the troubleshooting guides for common solutions and debugging steps.
