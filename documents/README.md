# FreshFlo Documentation

Welcome to the FreshFlo project documentation. This folder contains all guides, setup instructions, and technical documentation for the food surplus platform.

## 📁 Folder Structure

### 🔧 AWS Guides (`aws-guides/`)
AWS infrastructure setup and configuration documentation:
- `AWS_COGNITO_SETUP.md` - Complete AWS Cognito User Pool setup guide
- `AWS_AMPLIFY_DEPLOYMENT.md` - AWS Amplify deployment instructions  
- `COGNITO_DEBUG_GUIDE.md` - Troubleshooting AWS Cognito issues
- `COGNITO_TROUBLESHOOTING.md` - Common Cognito problems and solutions
- `S3_SETUP.md` - Amazon S3 bucket configuration
- `SECURE_S3_SETUP.md` - Secure S3 setup with proper permissions

### 🚀 Deployment Guides (`deployment-guides/`)
Production deployment and security documentation:
- `AMPLIFY_DEPLOYMENT_GUIDE.md` - Complete Amplify deployment workflow
- `BULLETPROOF_DEPLOYMENT_FIX.md` - Production-ready deployment fixes
- `BULLETPROOF_SECURE_SOLUTION.md` - Security hardening guide
- `DEPLOYMENT_SECURITY_CHECKLIST.md` - Pre-deployment security checklist

### ✨ Feature Documentation (`feature-docs/`)
Feature-specific implementation guides:
- `CSV_PHOTOS_FEATURE.md` - CSV upload with photos feature documentation

## 🔍 Quick Navigation

### Getting Started
1. Start with `aws-guides/AWS_COGNITO_SETUP.md` for authentication setup
2. Follow `aws-guides/S3_SETUP.md` for file storage configuration
3. Use `deployment-guides/AMPLIFY_DEPLOYMENT_GUIDE.md` for deployment

### Troubleshooting
- Authentication issues: `aws-guides/COGNITO_TROUBLESHOOTING.md`
- Deployment problems: `deployment-guides/BULLETPROOF_DEPLOYMENT_FIX.md`
- General debugging: `aws-guides/COGNITO_DEBUG_GUIDE.md`

### Security
- Production security: `deployment-guides/DEPLOYMENT_SECURITY_CHECKLIST.md`
- Secure infrastructure: `deployment-guides/BULLETPROOF_SECURE_SOLUTION.md`
